## 文件格式

每份文档是一个 Markdown 文件：开头是 `---` 包围的元数据（`doc_id`、`title`、`version_date`、`owner`），正文按 `## ` 标题切分成段落，段落 ID 为 `<doc_id>-S<序号>`。

直接修改 `docs/` 下的文件即可替换知识库内容，程序每次运行都会重新读取，不需要重建索引。

## 变体

`variants/` 下的目录用 `--overlay-dir` 叠加到 `docs/` 上，同 `doc_id` 的文档会被替换：

- `variants/d02_scoped/`：给 D02 加上"仅适用于市场部"的适用范围条款，用于验证"查证原文后冲突被消解"。
- `variants/d08_supersedes/`：新增 D08《费用报销管理办法（2024 修订）》，写明废止 D01、与 D02 不一致时以 D08 为准，报销期限 20 天。用于验证"写明替代关系的新版本应直接采用，不报冲突"。

用 `--exclude-docs D02` 可以临时移除某份文档，验证"只检索到 D01 且无冲突时依据 D01 回答"。
